# 🔥 视频行为分析系统V3｜YOLO驱动的智能安防监控平台，源码可直接部署

还在靠人工盯着监控屏幕？漏看、误报、响应不及时的问题，这套系统一次性解决！

**视频行为分析系统V3** 是一套基于深度学习的智能安防监控平台，支持摄像头实时接入、自定义布控区域、目标行为识别、异常报警与视频回溯，源码完整可部署，适合安防项目、课程设计、二次开发商用。

---

## ✨ 核心功能亮点

### 1. 可视化布控管理
- 支持在监控画面上**自由绘制多边形布控区域**，自定义警戒线、入侵区域
- 区域对齐、一键清空操作，适配各种场景（如马路、园区、河道）
- 布控区域可关联不同算法，实现越界、滞留、入侵等行为分析

### 2. 多协议视频流接入
- 支持 RTSP、HTTP、WS 等主流视频流协议，可直接接入摄像头、NVR
- 提供多种转发协议（HTTP/WS/FLV/MP4），支持实时预览与推流
- 支持本地视频文件回放与在线视频流分析，调试更方便

### 3. 智能目标检测与行为识别
- 内置YOLO系列目标检测算法，支持识别 `person`（行人）、`bicycle`（自行车）、`car`（车辆）等常见目标
- 实时标注目标框与置信度，画面直观显示识别结果
- 可扩展自定义算法，适配特定场景的行为分析需求

### 4. 报警管理与视频回溯
- 异常行为触发时自动记录报警视频片段，生成报警列表
- 支持报警视频在线回放、标记已读、批量删除，便于事件追溯
- 报警数据本地存储，可导出事件报告

### 5. 全流程可视化后台
- 侧边栏导航：主页、报警管理、算法管理、视频管理、布控管理
- 实时预览界面：视频流播放/停止控制、布控区域叠加、目标标注
- 界面响应式设计，支持PC端部署，操作直观易上手

---

## 🛠️ 系统架构与技术栈
- **前端**：Web端管理后台，实现视频预览、布控绘制、报警列表、参数配置
- **后端**：视频流接入、算法调度、报警处理、数据存储
- **核心算法**：基于YOLOv8/v26等目标检测模型，支持自定义权重替换
- **视频协议**：支持RTSP、HTTP、WS、FLV等主流协议，适配大部分监控设备
- **数据存储**：报警视频、日志、布控配置持久化存储

## 🚀 部署与运行流程
1. **配置环境**：安装Python、依赖库，部署前后端服务
2. **添加摄像头**：输入RTSP/HTTP地址，添加设备到系统
3. **绘制布控区域**：在监控画面上绘制警戒线、入侵区域
4. **启用算法分析**：选择目标检测算法，设置置信度、报警规则
5. **实时监控与报警**：系统自动识别目标行为，触发异常时生成报警记录
